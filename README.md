# Identificação de Fatores Associados ao AVC

Projeto desenvolvido no âmbito do **Processamento de Dados do Ramo Estudantil IEEE da Universidade Estadual de Maringá (UEM)**.

## Sobre o projeto

O projeto tem como objetivo investigar fatores associados à ocorrência de Acidente Vascular Cerebral (AVC) por meio de análise exploratória de dados e técnicas de aprendizado de máquina supervisionado.

A proposta consiste em explorar um conjunto de dados públicos, identificar padrões e associações relevantes e comparar o desempenho de diferentes modelos de classificação binária.

## Dataset

Será utilizado o [Stroke Prediction Dataset](https://www.kaggle.com/datasets/fedesoriano/stroke-prediction-dataset), disponibilizado no Kaggle por fedesoriano.

## Limitações

**Este projeto possui caráter exclusivamente acadêmico e experimental.**

Os modelos desenvolvidos não se destinam ao diagnóstico médico, à previsão clínica validada de eventos futuros ou à tomada de decisões em saúde. As associações identificadas não implicam relações de causalidade.
